테마

sanitize 모드 비교

같은 외부 입력을 title · 버튼 label · template 에 넣는다. 문자열 HTML 은 @daracl/core 의 sanitizeHtml 로 정리된다. 페이로드는 alert 대신 로그만 남긴다.

기본 권장

title · label 은 정리, template 은 신뢰된 HTML 로 그대로 (폼 유지). 외부 값을 template 에 넣으면 안 된다.

sanitize: true 외부 값

template 까지 정리한다. 외부 값을 본문에 표시할 때.

sanitize: false 위험

0.0.7 동작. 정리하지 않는다. 신뢰된 값에만 쓴다.

sanitize: 함수

앱의 sanitizer(DOMPurify 등)를 지정한다. 이 예제는 모든 태그를 글자로 바꾼다.

iframe url

url 은 http · https · mailto · tel · 상대 경로만 연다. 그 외는 iframe 을 만들지 않고 console.warn 을 남긴다.
